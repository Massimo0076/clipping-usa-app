Privacy Policy

Clipping USA · Last updated: November 17, 2026

Clipping USA is a personal tool used only by its owner to upload clips to the owner's YouTube channel StreamMoments through the YouTube Data API. It has no other users.

Data the tool uses

  • The OAuth token of the StreamMoments channel, created when the channel owner authorizes the tool with Google. It is the only Google user data the tool keeps.
  • The channel name, read once to confirm that the token belongs to the right channel.

The tool does not collect data about viewers, subscribers or any other person. It does not use cookies, analytics or advertising.

How the data is used

The token is used only to upload clips to the StreamMoments channel and to change the privacy status of those clips (for example from private to public). Nothing else.

Where the data is stored

The token is saved locally, in a file on the owner's own computer. It is never uploaded to any server other than Google's own API servers, never stored in the cloud and never put in any code repository.

Sharing

The data is never shared, sold or transferred to anyone. Clipping USA's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The token is kept only while the tool is in use. Deleting the local token file removes it. Access can also be revoked at any time from the Google Account page myaccount.google.com/permissions.

YouTube and Google

Clipping USA uses YouTube API Services. By using it you are also subject to the YouTube Terms of Service and the Google Privacy Policy.
