Clipping USA

A personal tool for the StreamMoments YouTube channel

What it is

Clipping USA is a private, personal tool. It turns long videos into short vertical clips and uploads them to one YouTube channel: StreamMoments, owned by the developer of this tool.

How it uses YouTube

The tool uses the YouTube Data API v3 with Google OAuth, authorized once by the channel owner. It only:

  • reads the name of the authorized channel, to confirm the clips go to the right channel;
  • uploads clips to that channel (as private videos by default);
  • changes the privacy status of those clips (for example from private to public) when the owner decides to publish them.

Who can use it

Nobody else. Clipping USA is not a public service: there is no sign-up, no website login and no other users. It runs only on the owner's computer.
